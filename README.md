# PPLAB2VAR13

Консольное приложение для поиска и проверки строк, похожих на номера банковских карт.

## Возможности

- Проверка введённой строки.
- Поиск номеров в тексте.
- Поиск в локальном файле.
- Поиск на веб-странице по URL.
- Определение платёжной системы.
- Проверка контрольной суммы алгоритмом Луна (кроме UnionPay).
- Сохранение результатов в историю.



## Используемые технологии

- Python
- `re` — регулярные выражения
- `requests` — получение содержимого веб-страниц
- `unittest` — модульное тестирование

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Запуск тестов

```bash
python -m unittest discover -v
```
